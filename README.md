# rag

Monorepo for three independent document-chat applications:

- **vani** — Vanilla RAG
- **wiki** — LLM Wiki
- **hybrid** — Hybrid RAG

Each application has its own `frontend/` and `backend/`. Shared project documentation belongs in `docs/`; shared infrastructure belongs in `infrastructure/` only where appropriate. See each application README for its scope.

This repository currently contains the initial scaffold only. Application code, dependencies, databases, and services have not been added.
