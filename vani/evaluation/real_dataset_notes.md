## Label caveats

- `expected_answer` and `answer_criteria` are evaluation references, not claims that VANI should produce an exact string. Human graders should allow equivalent Thai/English wording while checking each factual component.
- Tables and figures can extract with imperfect spacing. The cited physical page is verified, but a grader should visually confirm table cells in the PDF if a model's answer turns on a numeric value.
- Overview and analysis criteria are concise paraphrases. They are grounded in the cited pages but are not a complete measure of semantic faithfulness.
- All `expected_support` entries intentionally contain pages only. Chunk-level relevance must be labeled from verified indexed chunk records in a later safe step; it must not be inferred from page number or assumed chunk ordering.
